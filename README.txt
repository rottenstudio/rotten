RØTTEN WEBSITE UPLOAD

Extract this ZIP. Upload the files inside it to the ROOT of your GitHub repository:
- index.html (must be at the top level of the repository)
- assets/rotten-collection-lookbook.png (inside an assets folder)

On GitHub: Add file > Upload files. Upload index.html and the image under assets. Commit changes to main.
Do not upload the ZIP itself or put index.html inside another folder.
Website: https://rottenstudio.github.io/rotten/
